Career Exploration

Web Security Developer

As a Bachelor of Information Technology (Informatics Media) student, I aspire to become a Web Security Developer. This career combines my interest in web development with cybersecurity, allowing me to create secure and user-friendly web applications.

What is a Web Security Developer?

A Web Security Developer is responsible for creating, maintaining, and securing web applications against cyber threats. They ensure websites and web systems are safe from attacks such as SQL injection, cross-site scripting (XSS), and unauthorized access.

Job Responsibilities

  • Develop secure web applications.
  • Identify and fix security vulnerabilities.
  • Implement authentication and authorization systems.
  • Protect user data and privacy.
  • Perform security testing and code reviews.
  • Follow secure coding practices.

Required Skills

  • HTML, CSS, JavaScript
  • Database Management and Security
  • Secure Coding Practices
  • Linux Fundamentals
  • Git & GitHub
  • Problem Solving
  • Communication Skills
  • Networking Fundamentals

How My Degree Supports This Career

Throughout my Bachelor of Information Technology (Informatics Media), I have completed several courses that contribute to my goal of becoming a Web Security Developer.

  • Web Application Development – helped me understand website structure, user interfaces, and web application development.
  • Database – provided knowledge of data management, SQL, and database concepts which are important for secure web applications.
  • Data Communication and Networking – developed my understanding of networking concepts, protocols, and internet communication.
  • Information Security – introduced cybersecurity principles, threats, vulnerabilities, and protection techniques.
  • Special Topics in Network Security – enhanced my understanding of network attacks, security controls, and cybersecurity best practices.
  • Final Year Project – strengthened my research, problem-solving, documentation, and project management skills.

Relevance to Modern Cybersecurity

As organizations increasingly depend on websites and web applications, web security has become a critical component of cybersecurity. Web Security Developers help protect sensitive information, prevent cyberattacks, and ensure users can safely interact with online systems and services.

Why I Chose This Career

I chose the Web Security Developer career path because it combines my interests in web development, technology, and cybersecurity. During my studies, I enjoyed developing websites and learning how web applications function. As cyber threats continue to evolve, I believe web security plays an important role in protecting user information and online services.

My goal is to develop secure, reliable, and user-friendly web applications that provide both functionality and protection for users. This career allows me to combine technical skills, creativity, and problem-solving while contributing to a safer digital environment.
