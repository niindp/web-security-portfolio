Practical Learning Strategy

To achieve my goal of becoming a Web Security Developer, I plan to continuously improve my technical and professional skills through practical experience and independent learning.

  • Build secure web application projects using HTML, CSS, JavaScript, and PHP.
  • Maintain and improve my GitHub portfolio by uploading academic and personal projects.
  • Learn secure coding practices and common web vulnerabilities.
  • Study the OWASP Top 10 and web application security concepts.
  • Gain practical experience with Linux, Wireshark, and Burp Suite.
  • Participate in workshops, online courses, and cybersecurity certification programmes.

Industry Trends and Future Learning

The demand for Web Security Developers continues to increase as organisations rely heavily on web applications and online services. Modern web applications face security threats such as SQL Injection, Cross-Site Scripting (XSS), Cross-Site Request Forgery (CSRF), insecure APIs, and cloud-related vulnerabilities.

To remain competitive in this field, I plan to continuously update my knowledge of secure coding practices, OWASP Top 10 risks, cloud security, web application testing, and emerging cybersecurity technologies. Continuous learning will help me adapt to new threats and industry requirements throughout my career.

Personal Motivation

I chose the Web Security Developer career path because it combines my interests in web development, creativity, and cybersecurity. Throughout my studies in Information Technology (Informatics Media), I have enjoyed designing and developing websites as well as creating digital content. As cyber threats continue to increase, I believe secure web development is essential. My goal is to build web applications that are not only attractive and user-friendly but also secure and reliable for users.
